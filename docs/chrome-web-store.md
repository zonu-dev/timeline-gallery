## 提出 ZIP の作成

提出前チェックを一通り実行し、アップロード用 ZIP を作成する。

```sh
corepack pnpm run store:package
```

ZIP は `.output/` 以下に作成される。

```text
.output/timeline-gallery-1.0.0-chrome.zip
```

本番用マニフェストには以下だけが含まれていること。

- `storage` 権限
- `https://x.com/*` と `https://twitter.com/*` に対するコンテンツスクリプトの一致条件

開発用の `localhost`、`127.0.0.1`、`example.com` などは本番用マニフェストに含めない。

## ストア掲載画像

個人情報や実アカウントの投稿を含まない、申請用のモック画像を生成する。

```sh
corepack pnpm run store:assets
```

生成されるファイル:

- `store-assets/screenshot-01-gallery-mode-1280x800.png`
- `store-assets/screenshot-02-before-after-1280x800.png`
- `store-assets/screenshot-03-popup-toggle-1280x800.png`
- `store-assets/promo-small-440x280.png`

これらの画像は意図的にモック画面として作成している。公開許可のない X アカウント情報や実投稿が写ったスクリーンショットは使わない。

## ストア掲載情報

カテゴリ:

```text
ツール
```

パッケージの概要:

```text
Xのタイムラインを、余計な表示を抑えた画像ギャラリーに切り替えます。
```

説明:

```text
Timeline Gallery は、X (旧 Twitter) のタイムラインを、画像を見やすく並べるギャラリー表示に切り替えるための Chrome 拡張機能です。

データの外部送信は一切ありません。すべての処理はお使いのブラウザ内で完結します。

■ こんなときに使えます

- X のタイムラインで画像付きポストだけをまとめて見たいとき
- イラスト、写真、参考画像などを探すときに、テキスト中心のポストや周辺情報を減らしたいとき
- 左右のサイドメニューを隠して、タイムライン上の画像を広く表示したいとき
- 画像を見ながら、いいね・リポスト・ブックマークなどの基本操作はそのまま使いたいとき

■ ギャラリーモードで変わること

- 左サイドメニューと右サイドメニューを非表示にし、タイムライン部分の表示幅を広げます
- 画像が1枚だけ添付されたポストを中心に表示します
- 画像の付いていないポストは非表示にします
- 動画、GIF、複数画像ポスト、引用元カード、リプライ文脈のポストは初期設定では表示対象外です
- 投稿者情報、投稿時間、反応数、表示回数などの周辺情報を抑えて、画像を見やすくします
- いいね、リポスト、ブックマークなどの主要アクションは利用できます
- 広告は対象条件を満たす場合に表示し、通常のポストと区別できるようにします

■ 特徴

- 拡張機能アイコンをクリックして、ポップアップからギャラリーモードをオン / オフ
- デフォルトではギャラリーモードはオフ
- 設定は Chrome の保存領域に保存
- X 上の投稿データやログイン状態は変更しません
- 認証情報、Cookie、アクセストークンは読み取りません

■ プライバシー

本拡張機能は、利用状況・アクセス履歴・アカウント情報・ポスト内容など、いかなるデータも収集・送信しません。処理はすべてあなたのブラウザ内で完結します。

■ 注意事項

- 本拡張機能は X のタイムライン表示をローカルで見やすく整えるためのものです
- X の UI 変更により、一部の表示調整が一時的に効かなくなる可能性があります
- ギャラリーモードは画面上の表示を切り替えるだけで、X 上の投稿内容そのものは変更しません
- 本拡張機能は X Corp. とは関係のない独立したプロジェクトです
```

プライバシーポリシー URL:

```text
https://zoochigames.com/apps/timeline-gallery/privacy/index.ja.html
```

日本語向けの Chrome ウェブストア掲載では、この URL をプライバシーポリシー欄に入力する。

```text
X にログインした状態で x.com または twitter.com を開き、拡張機能のポップアップからギャラリーモードをオン / オフしてください。この拡張機能はローカルのタイムライン表示だけを変更し、設定は chrome.storage.local に保存します。テスト用アカウントの認証情報は不要で、認証情報や投稿内容は収集しません。
```

## アップロード前チェックリスト

アップロード前に確認すること。

- `corepack pnpm run store:package` を実行する
- `.output/chrome-mv3/manifest.json` に開発用の一致条件が含まれていないことを確認する
- `.output/chrome-mv3` を Chrome に読み込み、ポップアップからギャラリーモードを切り替えられることを確認する
- `https://zoochigames.com/apps/timeline-gallery/privacy/index.ja.html` が公開されていることを確認する
- ストア掲載画像に非公開の X アカウント情報や実投稿が含まれていないことを確認する
- アップロードする ZIP のバージョンが、すでに申請済みのバージョンより新しいことを確認する
