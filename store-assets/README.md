# Store Assets

Chrome ウェブストア掲載用のモック画像を置くディレクトリです。

生成コマンド:

```sh
corepack pnpm run store:assets
```

生成される PNG はモック UI のみを使用し、実際の X アカウント情報や投稿内容を含みません。

生成ファイル:

- `screenshot-01-gallery-mode-1280x800.png`
- `screenshot-02-before-after-1280x800.png`
- `screenshot-03-popup-toggle-1280x800.png`
- `promo-small-440x280.png`
